# Reference material the plans cite

Things a plan answers to that are not code: a picture the founder showed, a page from a competitor, a customer's own sheet.
Each file is named for what it is and dated for when it was shown, and the plan that cites it says what it took from it.

## `previous-build-dashboard-2026-09-05.jpg`

The previous build's dashboard ("Executive Dashboard"), the reference for M9's main dashboard (`Docs/M9_MAIN_DASHBOARD.md` §1, the founder's direction of 2026-09-05: "a main dashboard something like the above").
It is a photograph of the Windows laptop on which the screenshot `Screenshot 2026-09-05 005021.png` was open, because that is how the founder showed it: pasted into the planning session on 2026-09-05 at 21:12 local.
The original PNG lives on that laptop and was never on the Mac the repository is worked from; the photograph was recovered from the session's transcript on 2026-09-08 and committed as the thing the plan answers to.
Read it as a shape the founder liked, not a screen to restore: none of its labels exist in this codebase, and its figures are the old build's problems (a cost coverage of 109.0971% beside an "unavailable" chip), which is what the design plan's §1 says.
