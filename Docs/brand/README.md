# Faida brand handover

This folder contains the first brand direction and logo handover for Faida.

The recommended identity is **The Margin Fold**.
It combines the movement of a forwarded invoice, the rhythm of multiple branches, and an upward profit signal in one compact geometric mark.

The concept SVGs intentionally retain live type so the team can compare directions quickly.
Before formal trademark use or sending artwork to print, the selected wordmark should be optically refined and converted to outlines in a vector editor.
