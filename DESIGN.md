# Design system pointer

The complete brand and design system lives in `Docs/brand/faida-brand-guidelines.md`
(palette with usage ratios, Manrope/Inter typography with tabular numerals, voice, layout rules).
The implemented tokens are `apps/web/src/app/globals.css`; the product display rules are the
"Product display rules" section of `CLAUDE.md` / `AGENTS.md`.
Per-screen approved design directions live under `~/.gstack/projects/Ameen-Mammootty-faida/designs/`
(one folder per screen, with `approved.json`).
This file exists so tools and contributors that look for `DESIGN.md` find the system instead of
reporting "none" (added by the 2026-08-30 M6 design review).
